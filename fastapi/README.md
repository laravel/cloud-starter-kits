# FastAPI starter kit

A minimal FastAPI app on Python 3.14, ready to deploy to [Laravel Cloud](https://laravel.com/cloud) and built as a starting point for coding agents.

```sh
uv sync
uv run uvicorn app.main:app --reload --port 3000
```

The app runs on http://localhost:3000. Run the tests with `uv run pytest`.

Agents: read [AGENTS.md](AGENTS.md) first.
