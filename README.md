# Laravel Cloud starter kits

Minimal starter apps for [Laravel Cloud](https://laravel.com/cloud), built as starting points for coding agents. Each kit deploys to Cloud with no settings changed and tells an agent what it needs to build on it.

| Kit | Stack |
|---|---|
| [`nextjs`](nextjs) | Next.js, App Router, TypeScript, Tailwind CSS |
| [`nuxt`](nuxt) | Nuxt 4, server-side rendering, TypeScript, Tailwind CSS |
| [`express`](express) | Express 5, TypeScript on Node.js 24 |
| [`astro`](astro) | Astro, static output, Tailwind CSS |
| [`fastapi`](fastapi) | FastAPI, Python 3.14, uv |
| [`django`](django) | Django, Python 3.14, uv |
| [`rails`](rails) | Ruby on Rails 8.1, Ruby 4.0, Tailwind CSS |
| [`go`](go) | Go 1.27, standard library |
| [`laravel`](laravel) | Laravel 13, from `laravel/laravel` |
| [`laravel-react`](laravel-react) | Laravel React starter kit: Inertia, React, TypeScript |
| [`laravel-vue`](laravel-vue) | Laravel Vue starter kit: Inertia, Vue, TypeScript |
| [`laravel-livewire`](laravel-livewire) | Laravel Livewire starter kit: Livewire, Flux UI |
| [`laravel-svelte`](laravel-svelte) | Laravel Svelte starter kit: Inertia, Svelte, TypeScript |

Every kit except the Laravel ones has one page or route, one test, standard `test` and `lint` commands, and an `AGENTS.md` (with a `CLAUDE.md` pointing to it). None of them includes auth, a database, or a UI kit. They all use Tailwind CSS: Next.js, Nuxt, Astro, and Rails build it, and the rest load Tailwind's browser build from a CDN.

The Laravel kits are Laravel's own starter kits, as `composer create-project` creates them, generated by `tooling/sync-laravel` and refreshed daily. Don't edit them by hand: see [AGENTS.md](AGENTS.md#the-laravel-kits).
